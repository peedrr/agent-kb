# Openness audit — write path

This mockup is the template's own exemplar: it exists so `akb template write`
can prove the rules and the exemplar move together. A real research page files
one run's findings byte-faithfully — the body is the report as the run produced
it, anchored to the `as_of` snapshot date, with corrections handled by a
superseding page rather than by rewriting the snapshot.

## Findings

Findings are stated with their evidence inline, and the citing decision records
wikilink the page instead of restating it.
